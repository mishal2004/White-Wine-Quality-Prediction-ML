#  White Wine Quality Prediction – Machine Learning

##  Project Overview
This project focuses on analyzing white wine characteristics and predicting wine quality using Machine Learning techniques. It uses Python for data cleaning, exploratory data analysis (EDA), correlation analysis, and Linear Regression modeling.

##  Objectives
- Analyze white wine quality and chemical properties.
- Clean and preprocess the dataset.
- Identify important factors influencing wine quality.
- Explore relationships between chemical features.
- Build a Linear Regression model to predict wine quality.

##  Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

##  Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Correlation Analysis
6. Feature Transformation
7. Linear Regression Modeling
8. Model Evaluation

##  Key Features Analyzed
- Fixed Acidity
- Citric Acid
- Density
- pH
- Sulphates
- Alcohol
- Wine Quality

##  Project Files
- `whitewines ml project.ipynb` – Jupyter Notebook containing data analysis and machine learning code.
- `whitewines.csv` – Dataset used for the project.

##  Conclusion
This project demonstrates the application of Python and Machine Learning in wine quality analysis. It explores how chemical properties influence wine quality and demonstrates a Linear Regression approach to quality prediction.
